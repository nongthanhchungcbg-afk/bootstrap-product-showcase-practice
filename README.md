# Luma One — Trang giới thiệu sản phẩm

Bài thực hành Bootstrap Grid, spacing, Flexbox và Font Awesome. Trang giới thiệu sản phẩm có bố cục responsive, thông tin tính năng, thông số và các nút chọn màu có cập nhật trạng thái.

Mở `index.html` bằng trình duyệt. Bootstrap và Font Awesome được tải từ CDN; hình sản phẩm là SVG nằm trong thư mục dự án.
